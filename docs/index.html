01 / OVERVIEW

Features

01

Inspect a model

Read a PyTorch state dictionary, Python architecture, or both. Add a JSON config for context.

02

Find a method

Get short suggestions with links to papers and articles. See the current methods.

03

Compare profiles

Upload multiple models, switch between them, and compare their summaries.

04

Save reports

Export JSON or Markdown. Reopen JSON reports in the app later.

Runs locally. No PyTorch, GPU, or API key required. MockExplain suggests methods; it does not run them.

02 / SETUP

Get started

Install Python 3.10 or newer, then run these commands in a terminal:

git clone https://github.com/phamtrongthang123/MockExplain.git
cd MockExplain
python3 -m mockexplain

Open http://127.0.0.1:8000. Keep the terminal open while using the app; press Ctrl + C to stop it.

If port 8000 is busy, run python3 -m mockexplain --port 8001 and open http://127.0.0.1:8001.

03 / WALKTHROUGH

Try the examples

1

Upload a CNN

Click Upload model and select examples/tiny_cnn.pt from the cloned repository.

In Model overview, expand the tensor or weight-sample sections. Under Suggested methods, open the Grad-CAM paper or select Details.

2

Compare a transformer

Upload examples/transformer.py. Explore its suggestions, then click Compare profiles. Use Model profile in the header to switch between models.

3

Save a report

Choose Save JSON report to save a report you can reopen with Open saved report, or Save Markdown for a readable copy. Profiles stay in the current browser tab, so save before refreshing or closing it.

04 / YOUR MODEL

Use your own model

Choose Upload model to select a .pt checkpoint, a .py architecture, or both, with an optional JSON config. Upload folder collects these formats from a folder; it must contain at most one of each. Combined uploads are limited to 128 MiB.

If you upload weights first, use Attach .py / config to add context in a new profile. The original profile stays available. MockExplain does not verify that the attached files match the checkpoint.

05 / GOOD TO KNOW

Limits

  • The .pt reader supports ordinary uncompressed PyTorch tensor state dictionaries. Full serialized models, sharded checkpoints, and safetensors are unsupported.
  • A model family is inferred from structural clues. Unknown structures may not receive a suggestion.
  • Weight statistics cover samples; suggestions are not measured results.

See the README for supported formats and inspection limits.
