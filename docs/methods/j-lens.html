METHOD GUIDE

J-lens

Read an intermediate activation in vocabulary space.

The Jacobian lens, or J-lens, is a way to examine an internal language-model activation as a ranked list of tokens. It asks which tokens that activation is, on average across contexts, disposed to make the model say. The readout is an approximation, not a transcript of everything the model represents.

The idea

A Jacobian describes how a small change to an activation affects a later activation. J-lens averages these local derivatives across a corpus and uses the resulting matrix to map an intermediate activation into the final-layer space. In a simplified form:

Jℓ = average(∂hfinal / ∂hℓ)
scores ≈ WU Jℓ hℓ

hℓ is the activation at layer ℓ, Jℓ is the averaged mapping, and WU maps the result to token scores. The first equation omits the details of averaging across prompts and token positions.

A tiny example

Imagine a two-dimensional activation [2, 1] and a fitted mapping that swaps its coordinates. The mapped vector is [1, 2]. If a toy output readout assigns one token to each coordinate, the second token receives the higher score. Real lenses use many dimensions and vocabulary tokens.

What you need

A compatible language model, tokenizer, input, activations, and a fitted J-lens—or a corpus-based fitting step. Its averaged linear readout can miss context-specific effects and concepts that span multiple tokens.
