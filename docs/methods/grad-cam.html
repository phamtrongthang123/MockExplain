METHOD GUIDE

Grad-CAM

Make a heatmap for a chosen model output.

Grad-CAM asks: for this input and this output score, which spatial regions have a positive association with that score? It combines a convolutional layer’s feature maps with gradients and produces a coarse heatmap that can be overlaid on an image.

The idea

First, average the gradient of the chosen score over each feature map. Then use those averages to combine the maps:

αk = (1 / Z) Σi,j ∂yc / ∂Akij
Lc = ReLU(Σk αkAk)

yc is the chosen output score (usually before softmax), Ak is feature map k, and Z is its number of spatial positions. ReLU keeps positive values and sets negative values to zero.

A tiny example

At one location, suppose two feature maps have values 3 and 1 and their gradient weights are 2 and −1. The heatmap value is ReLU(2 × 3 − 1 × 1) = 5. Repeating this at each location gives a map; the map is typically resized to the input image.

What you need

A runnable model, an input, a target score, a spatial convolutional layer, and gradients. A bright region highlights positive evidence in this approximation; it does not prove that the region caused the prediction. The map’s resolution is limited by the selected feature maps.
