METHOD GUIDE

Filter inspection

Read the weights of a convolution filter.

A convolutional layer applies small sets of weights, called filters, across an input. Each filter produces a feature map: a value at every position where it was applied. Looking at the weights is a way to ask what kind of local pattern a filter may respond to.

The idea

At one position, the layer multiplies each input value in a local patch by the corresponding weight and adds the results. In a simplified one-dimensional example, ignoring bias:

y = x1w1 + x2w2 + x3w3

Here x is the input patch, w the filter, and y the resulting value. For patch [1, 2, 3] and filter [−1, 0, 1], the result is −1 + 0 + 3 = 2. The filter responds to a change across the patch. Real image filters usually have two spatial dimensions and multiple channels.

What to look for

First-layer filters in an image model can sometimes be displayed as small images. Some resemble edges or colors. Later filters operate on learned features rather than pixels, so their weights are less directly interpretable. Looking at which inputs activate them can add useful context.

What you need

Access to the convolution weights and their layout. You can inspect weights without running the model, but a visual pattern in the weights alone does not establish what the model learned or why it made a prediction.
