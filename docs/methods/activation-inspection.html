METHOD GUIDE

Activation inspection

Compare the internal values a model produces for different inputs.

Activations are the intermediate values produced while a model processes an input. Inspecting them can help locate where two inputs begin to produce different internal patterns. This is a family of techniques rather than one particular algorithm.

The idea

For a simple layer, a common calculation is:

h = ReLU(Wx + b)

x is the layer’s input, W its weights, b a bias, and h the output activation. ReLU replaces negative values with zero. Transformer components use other operations too; this equation is just a small example.

A tiny example

If the values before ReLU are [−1, 2], the resulting activation is [0, 2]. For another input, [3, −1] becomes [3, 0]. The two inputs activate different coordinates in this toy layer. In practice, you might compare activations across examples, layers, or attention heads.

What you need

A runnable model, representative inputs, and a way to capture internal values. Tools such as TransformerLens expose activations for supported language models. An observed difference is a useful starting point, but it does not establish that the difference caused the output; interventions can help test that question.
